# 第一次使用 YN

[English](guide.en.md) · [首页](../README.md) · [完整参数](features.md)

YN 面向长篇小说和游戏本地化，可选择全 AI 翻译与校对、全人工翻译与编辑，或人与 AI 混合处理。本页对应 2.2.0；先用一小段原文熟悉流程，再处理整本小说或整批游戏文本。

## 选择工作方式

- **AI 翻译**：在启动页配置模型并使用“准备并启动翻译”。任务会核对参数和原文，再按行分块处理；可由多个 Agent 并发翻译，经过机械校验、独立复审和精确修复。
- **AI 校对**：绑定与原文逐行对应的已有译文，选择逐片精审或 Monte Carlo 分层抽样。校对会返回具体问题与完整替换建议，可设置自动应用，也可逐条人工处理。
- **人工或混合编辑**：生成原译文对照 HTML，直接修改译文；可选从选中行向 AI 提问、维护术语和角色资料，或只把部分任务交给 AI。

## 下载与模型

从 [Releases](https://github.com/TohmaN233/YN-translation-workshop/releases) 下载 Windows 安装版或便携版。使用 AI 相关功能时，在首页顶部配置供应商、模型和授权。AI 任务使用 YN 的配置；外部 Agent 发起任务也一样。

## 创建项目

选择原文和项目保存位置。TXT 支持单文件、文件夹与相邻行双语；EPUB 会提取工作文本；PDF 需有可选中文字。原输入保持只读。

语言方向和翻译风格是项目参数。默认每块 500 行、最多 3 个子 Agent；数量是并发上限，不是必须同时启动的工人数。

### 译名表与角色表

已有译名表、角色表或设定资料时，可让 AI 整理项目资料。这个入口可先创建项目，不要求已有译文；AI 整理并核查草稿后提交正式表，也可按需修改草稿。开始翻译后仍可在 HTML 中查看、编辑或删除条目。

## 启动翻译

简便准备会核对参数与实际内容。对你描述的保留要求，模型结合真实原文样例提出范围明确的规则候选；程序试跑规则并校验匹配，之后以 HTML 参数表中的同一组设置和翻译提示启动任务。翻译按行分块，可并发使用多个 Agent；每块经过机械校验，独立复审覆盖全部机械风险行和抽样普通行，失败行再由翻译 Agent 精确修复。已有译文可审计后选择性复用，停止的任务可续跑。你也可以先生成行对行 HTML，自行调整参数，再按需调用 AI。

保留规则按实际匹配位置保护内容，普通正文仍可翻译。自定义正则和查看匹配示例可用于按需调整规则，例如确认 `abc:` 只保护行首前缀而不锁住完整台词。用户明确要求不翻译的人名可记录为正式表中的“源词 → 原词”。

## 使用已有译文

绑定与原文行数对应的译文。旧译复用先机械快筛，再对风险行做语义审计；一次确认后保留可复用内容，只重译需要修复的行。译文与当前原文不匹配时，先解决绑定或行对齐问题。

## 校对与写出

校对需要与原文逐行对应的已有译文。逐片精审会语义检查负责范围内的每一行；Monte Carlo 将全量确定性扫描与分层抽样语义审查结合起来，抽样模式不会对每一行都做语义审查。校对结果定位具体行，包含问题依据和完整替换建议。

![校对建议的逐条接受、拒绝与编辑](yn-guide/assets/screens/proofread-review.png)

可选择将建议自动应用到 HTML，也可逐条接受、拒绝或编辑建议。AI 处理或人工编辑完成后，点击写入最终 TXT、批量写入或导出 EPUB/PDF。自动应用更新 HTML，最终文件通过写出入口保存。

## PDF、代码和公式

选择文字层 PDF。YN 先提取正文、代码／公式字形和图表等资产，机械整理逻辑结构，经过当前模型的结构修订和独立审计后生成审阅 HTML。模型翻译可译正文，代码、公式及参考文献保留原始字形。导出用当前译文和源资产重建结构化 HTML，再自动重排生成新 PDF，无原正文文本框长度限制。已有 HTML 打开不重新跑结构模型。支持范围和资产限制见 [PDF 说明](pdf.md)。

## 中断与项目搬移

先使用停止按钮并等待收尾，再关闭或搬移项目。恢复在调用模型前核查草稿和证据；必需绑定文件丢失时恢复文件，不要让模型反复重试。项目内路径按项目根解码；项目外原文、PDF 或参考需一并拷贝并重新绑定。

## 手机与局域网

在桌面应用开启 LAN 同步并设置 PIN，手机或平板打开页面给出的地址。可编辑译文、审阅建议和使用同一 Agent 会话；桌面 YN 必须持续运行。公网隧道由外部工具提供，请保护 PIN 和访问地址。

## 让外部 Agent 在后台使用

给 Codex 等 Agent 阅读 [官方 Agent API](agent-api.md)：先展示项目位置、模型和完整参数，得到用户确认后再准备并启动。接口是本地 stdio 协议与启动器，不是公开的网络服务；任务使用 YN 配置的模型，不使用外部 Agent 对话中的模型。
