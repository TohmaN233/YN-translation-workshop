Current acceptance scope

On 2026-10-13, the full local Windows x64 npm test run passed 223 test files under Node.js 24.14.1. Hidden Electron 39.8.10 / Node.js 22.22.1 verified PDF prescanning, translation, repair and independent review. package.json and the lockfile define versions.

This is local acceptance, not a public CI badge. Native Pi workflow regressions use controlled test Provider responses to verify scope, write and recovery contracts; they do not measure real-model translation quality. The test count is a dated snapshot.

Reproduce

Use Node.js 22.19 or newer and the repository lock:

npm ci
npm test

Run the cold PDF recovery regression alone:

node --experimental-strip-types tests/pdf-protected-recovery.test.mjs

See development and validation for real desktop/package checks and hidden Windows acceptance rules. Time, memory, retries and cache hits vary with model, material, machine and network. Stable prompts and 500-line chunks do not establish universal cost savings.

Detected failures and limits

Code can reject missing rows, damaged control tokens, unauthorized writes and incompatible proof. Independent AI review examines risky rows and stable samples; split proofreading covers its owned rows, while Monte Carlo samples. Models can miss mistranslations, pronouns, voice or logic. No uniform public blind evaluation is reported here.

Failures must not masquerade as completion. Missing required bindings, unretryable internal errors and no-progress repairs stop with drafts and diagnostics retained. PDF protection depends on document metadata and paint structure. Unsafe separation is rejected explicitly; see PDF limits.
