翻译、校对与资料准备

English · 首次使用

初翻

准备参数与保留规则 → 解析原文清单 → 领取行分块 → 写入草稿 → 机械校验 → 独立复审 → 精确修复 → 提交正式候选 → 全文终检。

分块以工作文本的行为边界，默认 500 行；PDF 的工作文本行是预处理后完整的逻辑单元，保留与原始页面及资产的映射。并发工人是上限；每块完成后清空模型上下文，已接受证据由 Host 保留。译名/角色只注入直接命中的参考，缺少资料时再检索。已识别的 PDF 代码/公式由 Host 固定，不进入可写正文。

疑似未译可以是专名等误报。主 Agent 核对原文与候选后，可用 confirmTranslationResidueSafe 逐行说明理由并确认，随后继续原写入／修复流程。确认在项目中保存且只适用于该行的确切文本，任一文本改变即失效；子 Agent 无法授权。此能力适用于 TXT、EPUB、PDF，其他格式与结构检查仍执行。

校对

绑定已有译文 → 扫描全部对齐行 → 逐片精审或分层抽样 → 提交带绝对行号的建议与证据 → 审阅/应用到 HTML → 用户写出文件。

建议译文携带与翻译相同的保留要求。风格和语义风险需结合上下文判断，不能把所有 warning 变成硬拒绝。Monte Carlo 的抽样覆盖与全文校对分开报告。

资料准备

读取参考 → 编辑译名和角色草稿 → 读取核查 → check → commit。没有译文也可新建项目；草稿可反复改，最后事务性提升为正式表。

停止与恢复

停止先取消 Pi 和工作池，再保存收尾状态。异常恢复在首笔模型请求前核验原文/草稿的行数、hash、范围所有权与复核证据。未变的通过证据保留，仅变化行重新审查。保护内容改写前保存写前收据，避免文件已更新但 checkpoint 未提交的窗口破坏冷恢复。

程序内部故障、必需文件缺失、无进展修复或有界重连耗尽会停止整条流程；用户停止取消自动恢复。恢复不是把所有已完成文本交给模型重翻。

实现入口：YN Host、Supervisor、子 Agent。
